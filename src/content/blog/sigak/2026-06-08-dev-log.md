# 2026-06-08 개발 로그: 라벨링 없이 포트폴리오 README와 데모 흐름 최신화

## 요약

오늘은 수동 라벨링 시간이 없는 상황에서 v0.1 포트폴리오 완성도를 올릴 수 있는 작업을 먼저 진행했다.
새 검색 품질 주장을 만들지 않고, 이미 검증된 collection/projection/search/graph smoke 흐름을 README와 로컬 데모 문서에 반영했다.
핵심은 `api-ready-2026-06-05` expanded benchmark를 억지로 진행하지 않고, 현재 커밋된 3-query smoke artifact를 “재현성 근거”로만 보여주는 것이다.

## 오늘 완료한 일

- `README.md`, `README.ko.md`
  - v0.1 포트폴리오 포지셔닝을 collection, PostgreSQL, Elasticsearch, Qdrant, Neo4j, hybrid search, graph-aware detail 흐름으로 갱신했다.
  - root README에 compact Mermaid architecture flow를 추가했다.
  - 로컬 실행 명령에 `neo4j`와 graph projection rebuild를 포함했다.
  - smoke evaluation artifact 확인 명령을 추가하고, 41개 article expanded benchmark 품질 주장은 reviewed label 이후로 남겼다.
- `docs/DEMO_FLOW.md`, `docs/DEMO_FLOW.ko.md`
  - “Neo4j graph projection은 아직 포함되지 않는다”는 오래된 제한 문구를 제거했다.
  - Neo4j graph projection rebuild와 public graph-context 확인 단계를 추가했다.
  - retrieval/graph smoke artifact를 읽는 Node 명령을 추가했다.
  - troubleshooting에 Neo4j rebuild와 빈 graph context 확인 포인트를 추가했다.
- `docs/STATUS.md`, `docs/STATUS.ko.md`
  - portfolio README/demo flow refresh 상태를 반영했다.
  - expanded benchmark는 reviewed label이 생길 때까지 pending으로 유지했다.
- `docs/ROADMAP.md`, `docs/ROADMAP.ko.md`
  - compact architecture diagram 추가와 1차 README/demo-flow refresh를 반영했다.
  - 최종 release packaging, real enrichment, larger labeled dataset, research dashboard는 남은 작업으로 유지했다.
- `docs/superpowers/plans/2026-06-08-portfolio-demo-docs-refresh.md`
  - 이번 문서 작업의 범위, stop condition, 검증 계획을 남겼다.

## 설계 고민 / 결정

라벨링 없이 benchmark를 확장하면 숫자는 만들 수 있어도 품질 근거가 되지 않는다.
그래서 이번에는 새 평가 결과를 만드는 대신, 이미 커밋된 smoke artifact를 README와 데모 문서에서 안전하게 확인할 수 있게 했다.
6개 article/3개 query 결과는 품질 결론이 아니라 pipeline 재현성 근거이고, 41개 article catalog는 다음 라벨링의 기준점으로만 설명한다.

또 README에는 별도 큰 문서 링크만 두지 않고 architecture flow를 바로 넣었다.
포트폴리오 리뷰어가 첫 화면에서 Spring Boot, FastAPI, PostgreSQL, Elasticsearch, Qdrant, Neo4j의 역할을 한 번에 볼 수 있게 하기 위해서다.

## 트레이드오프

- 얻은 것: 라벨링을 하지 않아도 프로젝트의 현재 vertical slice와 실행 흐름을 더 정확하게 보여줄 수 있다.
- 얻은 것: demo flow가 Neo4j graph projection과 graph-aware detail까지 포함해 최신 상태가 됐다.
- 미룬 것: 새 `api-ready-2026-06-05` label 작성, expanded retrieval benchmark, expanded graph-aware benchmark는 계속 미완이다.
- 주의점: 이번 세션에서는 runtime Docker smoke나 backend/frontend/AI test suite를 새로 실행하지 않았다. 문서 갱신과 artifact reference 검증 범위다.
