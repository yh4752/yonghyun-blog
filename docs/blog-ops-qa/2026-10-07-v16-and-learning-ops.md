## Learning Ops 준비

대상은 `yonghyun-blog/2026-05-31-frontmatter-validation`이다. 공개 질문 7개와 기존 개인 답변 노트가 있으며 발행 상태는 `published`다. 준비 단계에서는 기존 사용자 답변이나 면접 답변을 수정하지 않았다.

질문별 답변 노트의 `#### 첫 답변`과 `#### 면접용 30-60초 답변`을 기존 `extractSection()`이 읽지 못하는 호환성 문제를 확인했다. 점검 당시 판정은 `##` 제목만 찾았다. 이후 개인 노트 전용 파서를 추가해 질문별 답변 형식도 지원하도록 수정했다.

기존 노트를 보존하고 private progress manifest로 복습 흐름을 연결했다. 현재 원문과 질문 섹션의 hash, Git 제외 상태와 Dashboard 반영을 확인했다. 이후 사용자와 7개 주제의 첫 복습을 수행하고 개인 노트와 복습 상태를 갱신했다. 실제 답변, 보완점, 개인 학습 상태와 다음 복습일은 비공개 파일에만 기록한다.

## 발견한 항목과 다음 순서

1. 첫 복습에서 남긴 항목을 다음 개인 복습에서 다시 확인한다. 이번 운영 루프는 1회 수행했다.
2. 질문별 답변 인식 호환성 개선을 완료했다. 다음 사용에서 상태별 행동 문구가 명시적인 복습 지정과 원문 변경을 충분히 구분하는지 관찰한다.
3. 새 글 모달의 Close가 입력을 버린다는 안내 또는 입력 복원이 실제로 필요한지 판단한다.
4. 위 작성·복습 흐름을 사용한 뒤 PR assistant의 필요성을 다시 판단한다.

실제 전체 inventory에는 Sigak 원본 중 frontmatter 누락 4건과 pending-sync 1건도 보였다. 다른 저장소의 원고를 바꾸는 작업으로 분리해 추적하며, 이번 yonghyun-blog 검증 통과와 섞지 않는다.

## Learning Ops 호환성 개선 결과

- 기존 단일 답변 형식과 질문별 답변 형식을 모두 읽는다. 공용 공개 섹션 추출과 저장된 hash 계산은 유지했다.
- 첫 답변은 하나 이상 작성하면 인식하며, 최종 답변은 모든 질문에 있어야 준비 완료 후보로 본다. 질문별 노트에는 공개 질문 개수도 확인한다.
- 빈 목록·체크박스, 템플릿 안내와 뒤쪽 복습 로그로 미완성 답변을 채우지 않는다. 목록 형태의 불확실한 답변과 기존 형식의 하위 제목도 회귀 검증했다.
- 명시적인 manifest 상태와 복습 일정이 우선 적용된다. 기존 개인 노트와 manifest는 개선 전후 파일 hash가 동일했다. inventory에는 개인 답변 본문이 포함되지 않았다.
- 독립 코드 검토에서 발견한 세 가지 경계 사례를 재현한 뒤 보완했다. 최종 검토에서 추가 발견 사항은 없었다.
