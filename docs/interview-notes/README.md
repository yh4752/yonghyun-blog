# 면접 답변 노트 시스템

블로그 글의 마지막에 있는 `면접에서 설명할 수 있어야 할 질문`을 내 언어로 소화하기 위한 개인 학습 공간이다.

공개 블로그에는 질문과 학습 포인트만 둔다. 실제 답변 연습, 부족한 개념, 면접용 문장은 `docs/interview-notes/private/` 아래에 작성하고 git에는 올리지 않는다.

## 구조

```text
docs/interview-notes/
  README.md
  templates/
    article-answer-note.md
  private/              # gitignore 대상
    <project>/
      <post-slug>.md
```

## 작성 흐름

1. 블로그 글을 읽고 `면접에서 설명할 수 있어야 할 질문` 섹션을 확인한다.
2. `templates/article-answer-note.md`를 `private/<project>/<post-slug>.md`로 복사한다.
3. 각 질문마다 `첫 답변`, `부족한 개념`, `코드/문서 근거`, `면접용 답변`을 채운다.
4. 답변이 막히면 블로그 글의 `코드에서 다시 볼 지점` 섹션으로 돌아간다.
5. 면접용 답변은 외운 문장이 아니라, 30-60초 안에 말할 수 있는 내 설명으로 정리한다.

## 원칙

- 공개 글에는 질문을 남기고, 개인 노트에는 답변을 남긴다.
- 답변은 처음부터 완벽하게 쓰지 않는다. 모르는 지점을 드러내고 다시 채운다.
- "Codex가 구현했다"에서 끝내지 않고, 내가 검토한 이유와 내가 설명할 수 있는 근거를 남긴다.
- 민감한 개인정보, 회사별 면접 질문, 공개하면 안 되는 전략은 `private/`에만 둔다.

## 확장 계획

v0는 파일 기반 개인 노트다.

나중에 필요해지면 다음 순서로 확장한다.

1. `new:interview-note` 스크립트로 블로그 글의 질문을 읽어 노트를 자동 생성한다.
2. 블로그 상세 페이지에 `내 답변 메모` 토글을 추가하고 브라우저 `localStorage`에만 저장한다.
3. 정말 필요할 때만 인증이 있는 비공개 답변 저장소를 만든다.

지금은 v0만 유지한다. 학습 습관을 먼저 검증한 뒤 UI 기능을 붙이는 편이 안전하다.
